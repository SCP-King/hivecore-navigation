# N-01 当前约束与离线导航判定说明（2026-11-19）

本文汇总当前方案中已经明确的约束、离线地图点分类、任务显示隔离和已知缺口。
架构细节见 `docs/architecture.md` §3.15—§3.17。

## 1. 任务显示生命周期

原则：所有任务相关显示绑定 `task_id + goal_id + map_version`，旧任务不得残留影响下一次任务。

### 必须清除/失效

新目标、取消、到达、失败超时、急停、地图切换时：

- 全局路径、局部轨迹、候选样条；
- 目标虚拟机器人、终点包络、8 cm 误差圈；
- 包络冲突高亮、失败点标记；
- “规划成功/失败”文案；
- 旧局部目标点、恢复阶梯显示。

### 可以保留

- 地图本身（静态/实时/全局层）；
- 明确标为“历史”的机器人轨迹；
- 当前位姿、传感器状态、系统健康。

### 晚到消息

- 旧 `goal_id` 的 `/planning/global_path`、局部轨迹、包络冲突、执行反馈一律丢弃；
- GUI 以 `goal_id` 为主键，不以“最后收到”为准。

### 当前实现状态

| 项 | 状态 |
|---|---|
| 新目标清空旧全局路径 | 已实现 |
| 包络冲突按 `goal_id + final_goal` 绑定 | 已实现 |
| 旧局部候选/失败标记/历史轨迹活动态 | **未完全隔离，待补** |
| 细节点云模式包络冲突高亮 | 未实现（仅低耗栅格） |

## 2. 离线地图点分类

输入：固定 PCD（`/grid_map/static_occupancy`）+ 实时 `/cloud` + 地面平面 + 当前足迹。

### 判定顺序

```text
有限值/坐标系
→ 地面剔除（z ≤ 地面+3 cm）
→ 高度带（机身−0.25 ~ +0.90）
→ 当前足迹内自车剔除（z −0.80 ~ +0.90）
→ 静态占用格 / 实时命中格
→ 未知按可通行
```

### 分类表

| 点类型 | 是否障碍 | 说明 |
|---|---|---|
| 地面/地板散点 | 否 | `z ≤ 地面+3 cm` |
| 低于机身下沿 | 否 | 规划高度带外 |
| 高于机身上沿 | 否 | 规划高度带外 |
| 当前足迹内自车点（静态/实时） | 否 | 运行期过滤，仅当前位姿 |
| 当前足迹外历史自车点 | **是（风险）** | PCD 拖影，需预处理 |
| 静态 PCD 在高度带内 | **是（硬）** | 离线固定，不因实时没看到而清除 |
| 实时 `/cloud` 命中在高度带内 | **是（硬）** | 3 s 时效 |
| 实时射线穿过、静态层也空 | 否 | 观测空闲 |
| 实时空闲但静态层占用 | **是（静态仍硬）** | 离线不自动清静态 |
| 未观测/未知 | 否（可通行） | `unknown_as_obstacle=false` |
| 动态预测点 | 否（软） | 只降速，不直接判碰撞 |
| 地图外目标 | 未知/可扩展 | 不因出图直接拒绝 |

### 栅格与包络

- PCD 体素 0.05 m；规划栅格 0.10 m；
- 任一点落入栅格即该格占用；
- 碰撞 = 足迹多边形 + 6 cm 覆盖的任一格占用；
- 起点/终点包络是“车体摆位”检查，不是路径检查；
- `goal_occupied` 是膨胀格占用，`goal_footprint_occupied` 是车体角/边压障碍。

## 3. 当前规划/执行约束

### 规划

| 项 | 约束 |
|---|---|
| 起点包络 | 当前位姿 + 当前 yaw + URDF 足迹 + 6 cm |
| 终点包络 | 目标点 + 目标 yaw + 足迹 + 6 cm |
| 高度带 | 机身 −0.25 ~ +0.90 |
| 未知 | 可通行（`unknown_as_obstacle=false`） |
| 全局搜索 | 持久 2D 栅格，0.10 m，400 万格预算 |
| 局部窗口 | 30 m × 30 m × 5 m，0.10 m |
| 目标 yaw | 关闭“设置朝向”时冻结选点瞬间机身 yaw |
| 目标窗口外 | 允许扩展；起点必须在图内 |
| 旧路径 | 地图变化/无目标/新目标时失效 |

### 执行

| 项 | 约束 |
|---|---|
| 速度 | 默认 0.4 m/s，上限配置 ≤ 1.0 m/s |
| 加速度 | 0.25 m/s² |
| 横摆 | 0.45 rad/s |
| 转向 | 甲方原生 4WIS IK，转向速率 1.57 rad/s |
| 到点 | 位置 8 cm；勾选朝向时 ±6° |
| 时效 | 场景/反馈/机体/轮组 3 s |
| 纠偏碰撞 | 预测会碰撞或出场景 → 零速等待重规划 |
| 急停/手动 | 立即零速，手动优先 |
| 恢复 | 局部 15 → 全局 5 → 等待 |

## 3.1 膨胀参数来源（2026-11-19 核对）

| 项 | 原始 pinned SCAN-Planner（b055d15） | 当前工程 |
|---|---|---|
| XY 环境余量 | **无 `environment_margin`** | `grid_map.environment_margin`，代码默认 **0.0**，本工程 launch 设 **0.06 m** |
| XY 碰撞形状 | 双圆盘 `double_cylinder_radius=0.25`、`offset=0.18` | URDF 足迹多边形 + 6 cm |
| z 上膨胀 | `obstacles_inflation_z_up=0.1` | `0.90` |
| z 下膨胀 | `obstacles_inflation_z_down=0.4` | `0.25` |
| 自车过滤余量 | 无 | 静态/实时均 **0.06 m**，与规划余量一致 |

结论：**6 cm 是乙方新增的安全余量**，不是原始 SCAN-Planner 参数。原始框架没有 XY `environment_margin`，只有双圆盘半径/偏置和 z 向膨胀。

## 4. 离线模式特有约束

1. 静态 PCD 固定：实时“没看到”不等于空闲，默认不清静态障碍；
2. PCD 里的动态物体、历史自车点会永久成为障碍；
3. 运行期自车过滤只覆盖当前足迹，历史拖影需预处理 PCD；
4. 地面 profile 必须与 PCD 匹配，否则启动失败；
5. PCD 必须在 `map` 坐标系，且 `pcd_map_frame_asserted:=true`；
6. 实时 `/cloud` 仍参与当前障碍，离线不是“只用 PCD”；
7. 未知可通行，但执行期观测门控可能另有限制；
8. 目标在 PCD 外允许扩展，起点必须在图内。

## 5. 当前已知缺口

| 缺口 | 影响 | 处理 |
|---|---|---|
| PCD 历史自车点 | 路径别处被拖影挡 | 建图自车点滤除属上游建图职责，不在导航 GUI 内置清理入口 |
| 实时层自车点 | 已加当前足迹过滤；真实贴障可能被一并过滤 | 执行器/监视器原始场景仍是安全复核 |
| 本次运行历史自车点 | 已加位姿历史足迹过滤（0.25 m/0.2 rad 触发） | 旧 PCD 仍需离线清理 |
| 静态 PCD 预处理 | 规划源 0.10 m、地面+6cm ~ 地面+1.60m；统一高度带 | 见 `docs/unified_z_filter.md` |
| Raycast 去重 | 同一 0.10 m 体素只保留一条射线 | `grid_map.raycast_dedup_resolution` 可回退 |
| 自车过滤坐标/绕向 | 已修为机身相对坐标 + 绕向无关多边形 | 重建后需重启导航加载 |
| 自车过滤余量 | 0.02 → 0.06 m，覆盖足迹外、膨胀带内的腿/轮点 | 与规划 6 cm 余量一致 |
| 窗口外目标可见性 | 局部栅格不覆盖 | 已发布 `/grid_map/global_grid`，GUI 暗色底图 |
| 旧局部候选/失败标记残留 | 旧任务显示影响新任务 | 按 §3.16 补 GUI 清理 |
| `WAITING_FOR_REPLAN` 纠偏碰撞 | 贴边时反复暂停 | 等重规划或人工挪车，暂无自动倒车 |

| `fault_evidence`/`fault_action` | 只有主域，缺证据/动作 | 下一版补 |
| `/planning/envelope_conflict` 话题 | 当前仅 GUI 本地高亮 | 下一版发布 JSON |

## 7. 变更原则

- 任何“清除旧显示”不得删除地图数据；
- 任何“放行”不得绕过急停/手动接管/真实障碍；
- 旧任务消息必须按 `goal_id` 丢弃，不按到达顺序；
- 归因必须有证据；无证据显示 `unknown`，不猜测。
