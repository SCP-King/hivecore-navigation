## 3 融合栅格与语义(设计核心,含修正记录)

分辨率 `0.10 m`,网格原点 `(-20, -18) m`,范围 `65×56 m`(650×560 格)。列索引
约定与 OccupancyGrid 消息一致:`col = iy*sx + ix`,data 行主序,width=sx,height=sy。
值:`-1=UNKNOWN / 0=FREE / 100=OCCUPIED`。

### 3.1 修正记录(重要,2026-10-28)

初版分析原型用 `order=np.argsort(z)` 后取 `np.unique(cs, return_index=True)`
的分组 **有误**:按 z 排序后同一 XY 列的点不连续,`seg = zs[fi:fi+cnt]` 混入
其他列的点,曾得出"列内 z 跨度≤2mm、静态 OCC=0、目标可达"等**错误结论**。
本版与实现一律使用 **`np.lexsort((z, col))` 按列分组、组内按 z 升序**,
`unique(col, return_index+counts)` 的切片 `zs[start:start+count]` 即该列全部点。
**并用逐列参考循环实现交叉验证向量化实现(不一致格数=0,PASS)**。

### 3.2 静态层判定(每列)

对每个 0.10m XY 列,取列内**全部点**(修正分组):

| 条件 | 归格 | 依据 |
|------|------|------|
| 列内无任何点 | **UNKNOWN**(-1) | 无观测 → 不视为自由(用户铁律) |
| `列最低点 zmin > floor_max`(0.5m) | **UNKNOWN**(-1) | 只有高层结构/悬空点、无地面证据 → 不视为自由 |
| `zmin ≤ floor_max` 且带内点数 `≥ min_band_points` | **OCCUPIED**(100) | 有地面证据且在 (zmin+0.15, zmin+robot_h] 带内有足够静态点 → 静态障碍 |
| 其余(zmin ≤ floor_max 且带内点不足) | **FREE**(0) | 观察到可通行地面且无障碍阻挡 |

- 带内噪声门 `min_band_points`(默认 1=严格;2=过滤孤立单点噪声,评估用)。
- 关键参数:`robot_h`(车体可通过高度,默认 **1.5,乙方无据需甲方确认——开放项**)、
  `obs_bottom=0.15`、`floor_max=0.5`、`min_band_points=1`。

### 3.3 动态层判定

- `/grid_map/occupancy` 中任意点落入某列 → 该列 **OCCUPIED**(动态障碍;上游已
  地面过滤,不做 z 裁剪)。实时层**只增占用、不置自由**。

### 3.4 融合与膨胀

- `fused`:OCC = 静态 ∪ 动态(及**膨胀环**);FREE 只在静态=0 且未被膨胀/占用覆盖
  时成立;其余 UNKNOWN。`safety_radius=0.35m`(乙方无车体外廓数据,为**待确认
  假设**;Hive2 URDF 髋关节 b_x=±0.28/b_y=±0.135 + 轮系外挂提示实际半径量级
  0.2~0.45m,真机验收须按甲方实测值覆盖)。

### 3.5 修正后的静态连通性实况(诚实结论,2026-10-28 实测)

在目标 PCD、robot_h=1.5、min_band_points=1、safety=0.35m 下:

- 静态分类:FREE=10768、OCC=4826、UNKNOWN=348406(0.10m 格)。
- **FREE 碎裂为 761 个连通分量**;最大分量 0 = 54 m²(bbox x[5.5,17.9]
  y[1.8,18.2],地图中东部),分量 1 = 21 m²(bbox x[-2.9,7.6] y[-3.5,5.3],
  起止点所在区域),其余 ≤5 m²。
- **起点(0,0)吸附 0.1m 后所处分量 = 分量 1(21 m²);膨胀后该分量仅 236 格
  (≈2 m²),最远可达约 2.8m@(2.8,0.2)**。
- **本图不存在自原点出发的长程静态自由走廊**;bag 穿行最远点 (16.728,12.553)
  在静态层不可达(吸附 0m 后不在同分量)。
- 轨迹 233 点:124 落 FREE(其中仅 ~82 在分量 1、42 在分量 0,其余散布小分量),
  10 落 OCC,99 落 UNKNOWN。**主导瓶颈 = PCD 地面点覆盖不足**:沿机器人实际
  行进路线的列大量无低 z 点(车体遮蔽/树冠遮挡/建图输出降采样),其次部分 OCC
  为多层地形误分类(列最低点在低层、机器人开在上层)。
- 噪声门(min_band_points=2)对连通性改善有限(236→262 格),印证瓶颈是**数据
  覆盖**而非阈值。

**设计取舍(已定)**:A* 离线验证不预设长程可达。静态层照常提供"地面证据=FREE、
其余 UNKNOWN/OCC"的严格语义;**可验证的 A* 用例 = 真实地图可达分量内的远端
实例**(分量 1 或 0 内部),并在报告中如实给出长程不可达及原因。实时新地面/自由
通道(`scan` 自由射线外发)列为 Phase 6 增强项,不在本设计内用轨迹/合成数据
"凑"出通路。

## 4 A* 规划接口(最小,可离线验证)

- 订阅 `/map/fusion/fused_grid`;start/goal 由参数或 `/planning/goal`
  (PoseStamped)给定。8 连通;欧氏启发(admissible);格代价 1/√2。
- **可通行 = FREE(0)**;OCCUPIED 与 UNKNOWN 一律封闭(守铁律)。
- 起终点不在 FREE → 最近 FREE 吸附(≤ snap_radius=1.5m,记录距离)。
- 输出 `/plan/path`(nav_msgs/Path,frame=map)+ `/plan/result`(std_msgs/String 诊断)。
  无控制器、无 `/cmd_vel*`、无 TF。
- 失败(不可达/无路径)输出空 Path + 明确原因(供离线测试直接断言)。
