# 动态统一路径与在线 CBF 速度过滤

## 对外路径

`/planning/global_path` 和 `/n01/live_navigation/hive2_candidate_path` 保留为内部输入。
新节点 `n01_navigation_path` 对外发布 `/n01/navigation/path`：本次有效局部段
替换原始全局对应路段，拼接保留后续全局路线和最终目标。

拼接要求同一 map 帧、同一目标的轨迹、局部段在有效时间窗内、拼接间距不超过
0.30 m、接续方向夹角不超过 60°。异常时发布无效状态并清空可执行路径。
旧目标的局部段不能跨目标拼接。

`/n01/navigation/path_status` 声明已验证前缀点数及路径时间戳。执行器只在
该前缀内选择预瞄点，未验证的远端全局参考不得当作可执行走廊。
到达前缀末端而前方尚未验证时停车等待更新。
GUI 和导航 RViz 改为显示统一路径，内部局部规划状态保留在高级信息中。

## 到点与执行

执行器跟随统一路径；距离最终目标小于 0.10 m 时锁定 ARRIVED 并零速。
默认会话距离/时长限制均为 0（无固定测试截断）。运行中仍强制检查实时定位、
路径有效前缀、系统健康、候选评估和急停。显式设置的短距离测试上限继续有效。

本次部署没有自动开启新执行器。先前 0.2 m 范围的现场确认不覆盖更长路线。
测试中发现 GUI 旧版执行器仍在线，已按专属组 55617 正常停止；定位和 GUI 保留。

## CBF

在线模块是标量前进速度 CBF-QP 投影，不是离线 MPC-D-CBF 求解器：

```
minimize (v-v_nom)^2
0 <= v <= v_nom
2*r·(v*heading-v_obstacle) + alpha*(r·r-R²) >= 0
```

所有实时障碍点约束和动态轨迹约束共同形成速度区间。SCAN 负责几何改路，
CBF 负责限制实际前进速度或停车；无可行速度、点云/动态状态陈旧、非法数据时零速。
不通过 CBF 主动提高名义速度。默认机体半径 0.55 m；动态簇中心附加保守半径。
现有动态跟踪仍是候选估计，缺少经实机标定的完整外廓和预测误差界，因此
这些约束不构成物理安全认证，需现场动态障碍测试。
