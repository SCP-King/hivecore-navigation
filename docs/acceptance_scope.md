# N-01 离线建图/定位导航验收边界（2026-11-18）

## 1. 交付主线

| 模式 | 定位 | 说明 |
|---|---|---|
| 离线 PCD + 定位导航 | **验收主线** | 固定地图，可重复、可回归 |
| 实时建图导航 | 演示/试验特性 | 受场景时效、建图漂移、自车点影响，不作为主验收 |
| 实时障碍层 | 两种模式共用 | 固定/累积地图 + 当前 `/cloud` 障碍 |

## 2. 离线模式“够用线”

### 必须通过

1. 加载 PCD、定位进入 tracking，导航 PCD/地面同步；
2. 选点后全局 A* 能出路径，目标在合理范围；
3. 局部 SCAN 跟踪，静态/动态障碍能停/绕；
4. 目标可选、可取消、可重发；
5. 急停、手动接管、反馈中断能安全停车；
6. 速度 0.4 m/s、加速度 0.25 m/s²、转向/横摆限制生效；
7. GUI 显示地图、路径、状态、失败原因；
8. 参数可调、可回滚。

### 应该通过

9. 目标点虚拟 URDF/足迹预览；
10. 终点足迹检查与 `goal_footprint_occupied`；
11. 起点自车点不影响规划（运行期足迹过滤 + PCD 预处理）；
12. 恢复阶梯：局部 15 → 全局 5 → 等待；
13. 地图变化/旧路径失效提示；
14. 全局 2D 栅格在 GUI 可见（窗口外障碍）。

### 明确不做（本轮）

- 实时建图长期稳定性调优；
- 点击拖拽箭头（数值 yaw 已够）；
- 路径像素审计叠加层；
- 自动倒车逃逸；
- CBF、frontier、覆盖门控。

## 3. 离线验收前必须确认

- PCD 已在建图端或离线工具中去除自车点/拖影；
- PCD 在 `map` 坐标系，地面平面/坡度正确；
- 点位在 30 m 窗口内外都能看到障碍（全局层已发布）；
- 每个验收区域记录：起点、目标、yaw、是否勾选朝向、结果、停车原因、恢复时间。

## 4. 当前已知限制

- 运行期自车过滤只覆盖当前位姿足迹；PCD 历史自车点仍需预处理；
- 目标在 30 m 窗口外时，局部栅格不覆盖，靠全局层显示；
- `WAITING_FOR_REPLAN：纠偏指令会碰撞或超出场景` 需场景/路径更新或人工挪车；
- 急停必须人工释放，软件不绕过；
- 实时建图模式不作为主验收。

## 5. 本轮代码对齐

- 发布 `/grid_map/global_grid`，GUI 以暗色底图显示窗口外全局障碍；
- 目标失败原因补充“膨胀障碍”说明；
- 目标 yaw：关闭“设置朝向”时冻结选点那一刻的机身 yaw，虚拟机器人不再随车转；
- 细节点云 `goal_yaw` 作用域修复；
- 终点虚拟 URDF + 红/绿/灰足迹 + 8 cm 误差圈。


当前约束、离线点分类与已知缺口汇总：见 `docs/current_constraints.md`。
