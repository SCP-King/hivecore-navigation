## 关键差异/容易误读处

1. 旧 PDF《Hivecore SLAM Services GUI》讲的是 GUI 操作界面；安装包新手册才明确当前 `hivecore_slam3d` 的 outer role/inner session FSM。
2. 旧资料中的 `hivecore_lidar_slam3d` 不能直接等同于当前 `hivecore_slam3d`；当前节点为 `slam3d_node`，服务和状态字段以安装包 IDL/手册为准。
3. GUI 启动不等于定位启动。`gui_slam_console` 是 Idle hub；当前运行参数实测 `outer_role=idle`、`localization.session_mode=stopped`。
4. 地图文件存在不等于当前 node loaded。当前实际地图文件是 `/home/demo/lyy/slam_data/maps/nav_map_2026_10_10-20_54_46.pcd`，而 node 参数默认 `localization.map_path=/root/resources_storage/cloud_map_pgo.pcd`，且 status 明确 `config_context_map_loaded=false`。
5. `Session Start` 不等于 Tracking；安装版状态机有独立 `enter_tracking`。
6. `/localization_status` 存在不等于定位有效；必须看 registration 和 control 字段。
7. 安装版文档要求 `gui_slam_console`、`mapping_console`、`localization_console` 不能叠加；重复 RSP/TF 是启动配置风险，非地图文件本身证据。
