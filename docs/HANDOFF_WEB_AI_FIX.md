# N-01 离线地图与导航验收方案

以甲方 SLAM 保存的 PCD 作为定位和导航共同输入，记录文件哈希、地图坐标和地面参数。定位建立机身位姿后单独启动导航。验收只发规划目标。

- 建图画面显示地图障碍和扫描覆盖。白色只表示有扫描证据的空闲，遮挡、缺测和未记录覆盖的旧 PCD 保持未知。
- 导航画面显示整图障碍，局部实时障碍叠加。静态灰紫、实时青色、规划膨胀琥珀色。默认画面保留机器人、目标及实际路径。
- 导航白区取全局 A* 实际搜索掩码与已知空闲证据的交集。连通搜索从真实起点开始。导航收到位姿、地图和包络后，每秒发布选点预检栅格。首个快照生成前显示等待，禁止用附近空闲格替代起点。
- 选点与提交共用规划侧膨胀规则。提交目标不触发界面切换，预检层按独立节拍刷新。撤销只在提交时对目标周围临时清除膨胀的例外。超出预检边界的目标由正式规划判断。正式提交仍由局部三维地图检查目标朝向和足迹，再运行全局 A* 与局部 SCAN。未知、膨胀阻挡和搜索无路分别提示。
- 验收用同一 PCD 复查墙边、窄门、断路和窗口外目标，记录起终点及失败阶段。另验证仅启动建图时覆盖层更新。地图覆盖持久化单独验收，旧 PCD 不推断历史空闲。

启动入口为 `bash scripts/n01 gui`。具体客户指标见 [验收清单](acceptance_checklist_customer.md)。
