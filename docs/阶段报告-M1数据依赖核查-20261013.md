## 三、实测失败（须甲方处理）

**双 RSP 静态 TF 冲突（FAIL，阻断项）**
- 现象：`/tf_static` 上 `base_footprint→base_link` 有 **2 个不同发布者**（两个 robot_state_publisher），6 次独立采样 z 在 0.3 / 0.9 间摇摆（0.3,0.3,0.9,0.9,0.3）。
- 来源①：运动栈 URDF z=0.9
  `/opt/hivecore/hive2-motion/1.0.0/install/share/hive2_driver/description/hive2.config.xacro`
  （joint `base_footprint_joint` origin xyz="0 0 0.90"）
- 来源②：SLAM 栈 URDF z=0.3
  `/home/demo/release_slam_3d/install/hivecore_robot_description/share/hivecore_robot_description/urdf/hivecore_robot.urdf.xacro`
  （`footprint_xyz` 默认 "0 0 0.3"，joint `base_footprint_to_base_link`）
- 影响：任何查询 base_footprint→base_link 的地方 z 会在 0.3/0.9 抖动。
- 乙方规避（M1 下）：controller / local_map / gate 均直接消费 /odom 消息 + lidar_link/livox_frame 静态边，**不查 base_footprint→base_link** → M1 主链路不受此边影响；但 planner/可视化若查会受影响。
- 处理：**需甲方确认**正确几何（现场实测 z=0.9，参数文本§9）并在 SLAM 栈停用冲突 RSP。乙方不代做、不掩盖。
