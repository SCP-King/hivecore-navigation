# 蜂核科技 GUI-SLAM 定位 Pose/TF 对外发布异常反馈

**反馈日期：**2026 年 10 月 16 日  
**运行环境：**Hive2 真机、ROS2 Humble、ROS_DOMAIN_ID=55  
**问题性质：**定位内部状态正常，但外部 ROS2 无法收到定位 Pose/TF

## 一、问题概述

目前 GUI-SLAM 已成功加载 Context Map，进入 Localization / Tracking，定位配准正常。

SLAM 状态显示：

```yaml
registration_output_pose_published: true
registration_output_tf_published: true
control_signal_enable_publish_pose: true
control_signal_enable_publish_tf: true
```

但现场外部 ROS2 订阅结果为：

- `/robot_pose`：连续 15 秒接收 **0 帧**。
- `/tf`：连续 15 秒收到 316 条消息，但没有任何 `map` 或 `odom` 动态 TF 边。
- `tf2_echo map lidar_link`：持续提示 `Invalid frame ID "map"`。

**即 SLAM 内部报告定位结果已发布，但外部 ROS2 实际未收到定位 Pose 和 map TF。**

目前原因尚未确定，需要甲方针对定位输出链路进行确认。

```text

```

同时，定位状态曾显示：


建议重点检查：

- `holding pose board, no pose tick` 是否表示当前没有生成新的定位位姿更新。

- IMU 数据缺失或同步异常是否阻止定位 Pose/TF 对外发布。

**以上仅为排查线索，尚未确认这些警告与 Pose/TF 无输出存在因果关系。**
