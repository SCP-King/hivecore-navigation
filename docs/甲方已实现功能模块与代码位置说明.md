## 1. 底盘运动系统(Hive2 Motion)

**作用**:全向轮底盘驱动、运动控制、里程计、真人遥控、Web 调试,以及导航需要订阅/发布的底盘接口。这是乙方导航最核心的对接底座。

**代码总目录**:`/opt/hivecore/hive2-motion/1.0.0/`
固定安装入口由 `current` 软链指向:`/opt/hivecore/hive2-motion/current -> 1.0.0`。
配置"真源"在 `config/`;`install/share/` 下为运行时拷贝副本,**改参数必须改 `config/` 并重新部署**。

### 1.1 启动与一键入口

| 文件 | 作用 |
|---|---|
| `/home/demo/Desktop/Hive2底盘启动.desktop` | 桌面入口 → 调 launcher |
| `/opt/hivecore/hive2-motion/1.0.0/scripts/start_hive2_motion_launcher.sh` | 解析 SDK 根、补 DISPLAY、调主脚本 |
| `/opt/hivecore/hive2-motion/1.0.0/scripts/start_hive2_motion.sh` | **主启动**,开 3 Tab:EtherCAT / driver / controller |

启动流程(两层):
1. **驱动层**:`ros2 launch hive2_driver hive2_driver.launch.py`
   (单一 controller_manager @1000Hz,含 EtherCAT 腿 / USB2CAN 轮 / IMU)
2. **运动层**:`ros2 launch hive2_controller hive2_controller.launch.py`
   (必须等待 EtherCAT 从站全部 OP 后再启)

### 1.3 底盘参数(几何 / 速度 / 安全)

| 配置文件 | 说明 |
|---|---|
| `/opt/hivecore/hive2-motion/1.0.0/config/hive2_driver/robot_motion.yaml` | **唯一参数真源**:controller_manager、底盘几何与限速 |
| `/opt/hivecore/hive2-motion/1.0.0/config/wheel_controller_refactor/hive2_chassis_params.yaml` | Hive2 监督/遥操参数 |
| `/opt/hivecore/hive2-motion/1.0.0/config/wheel_controller_refactor/hive3_chassis_params.yaml` | Hive3 版(速度上限 1.0 m/s) |
| `/opt/hivecore/hive2-motion/1.0.0/config/wheel_controller_refactor/person_follow_params.yaml` | 人员跟随 |

关键数值(Hive2 `robot_motion.yaml`):
- 几何:`wheel_radius 0.095 m`、`wheel_base_x 0.56 m`(前后轴距)、`wheel_base_y 0.27 m`(左右轮距)、`delta_y 0.085 m`
- 速度:`max_linear_speed 2.0 m/s`、`omega_per_linear 1.25`、`max_linear_acc 1.0`、`max_angular_acc 2.0`
- 控制:`control_rate 50 Hz`、`cmd_timeout 0.2 s`(超时自动停车)、controller_manager `update_rate 1000`、RT 优先级 99、绑核 `cpu_affinity 7`
- 里程计:轮式积分 + 可选 IMU yaw EKF(`chassis.odom.imu_fusion: true`,sensor `lpms_imu`);无 IMU 时驱动层自动降级纯轮式

> ⚠️ N-01 要求速度 ≤1.0 m/s。Hive2 默认 `max_linear_speed=2.0`,Hive3 版本为 1.0。做导航前需按需求收敛到 1.0 m/s。

### 1.4 底盘对外接口(导航对接点)

**输入(订阅)**:
- `/cmd_vel`(`geometry_msgs/Twist`) —— **导航的速度指令入口**,`steer_drive_node` 权威输入
- `/cmd_wheel`(`interfaces/CmdWheel`) —— 归一化遥操输入,可选
- `/chassis_dec_stop`、`/estop` —— 安全减速/急停

**输出(发布)**:
- `/odom`(`nav_msgs/Odometry`) —— 车轮里程计 @约 50 Hz
- `/chassis_state`(`interfaces/ChassisState`) —— 底盘综合状态 @10 Hz(FSM/轮故障)
- `/chassis_controller/rt_command`(ChassisRtCommand)、`/chassis_controller/rt_status`(ChassisRtStatus,~50Hz,FK 反馈)
- `/tf`(odom→base_link)、`/joint_states`、`/wheels_can/joint_state`、`/ethercat/joint_state`、`/lpms/imu/data`

接口消息定义:`/opt/hivecore/hive2-motion/1.0.0/install/share/interfaces/`
(详见 §5 SDK,同一套 IDL)

关键话题(感知层 → SLAM):
