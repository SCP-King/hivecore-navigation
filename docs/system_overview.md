# N-01 系统总览（2026-11-19）

## 1. 整体分层

```
甲方 SLAM（slam3d_20261118）
  PCD / 定位 / /cloud / /body_pose / /loc_status
        │
乙方 N-01 适配与桥接
  localization_adapter / live_scan_bridge
        │
导航算法（scan_planner）
  静态地图 + GridMap（局部 3D + 持久全局 2D）
  → 全局 A* → 局部 SCAN → 可行性/恢复
        │
安全与执行边界
  runtime supervisor / goal gate / safety monitor
  trajectory monitor / dynamic tracker / controller
        │
甲方底盘（Hive2 4WIS，规划默认不启动执行）
        │
GUI + 工具 + 文档 + 验收
```

## 2. 数据流

```
PCD + 定位 + /cloud + 目标
  → 静态层/实时层/全局层
  → 全局路径（2D A*，足迹/双圆柱）
  → 局部 SCAN（3D 体素 + B 样条）
  → 轨迹审核/执行包
  → 底盘速度（需显式授权）
```

## 3. 运行模式

| 模式 | 定位 | 地图 |
|---|---|---|
| 离线 PCD 导航 | 甲方定位 tracking | 固定 PCD（主验收） |
| 实时建图导航 | 甲方 SLAM | `/cloud_map` 累积（试验） |
| 规划-only | 定位 + 规划 | 不启动执行器 |

- 起点/终点包络：URDF 足迹 + 6 cm，目标 yaw 可设；
- 自车过滤：当前足迹内静态/实时点剔除；
- 离线静态层固定，不按每帧扫描刷新；
- PCD 规划源 0.10 m、z −1.2~1.2 m；
- raycast 0.10 m 体素去重；
- 包络冲突高亮（GUI 本地）；
- 任务显示清理（新目标/选点/取消）；
- 导航期间锁定导航视图，不自动跳定位/建图；
- 规划模型启动切换：URDF / 双圆柱，显示始终 URDF；
- 故障域前缀（地图/定位/规划/执行/底盘/感知/配置/人工/数据不足）；
- PCD 历史拖影离线清理工具（轨迹 + 历史足迹）。

## 7. 当前限制

- PCD 历史自车点必须离线清理，运行期只覆盖当前足迹；
- 高障碍默认不参与规划（z 窗口 1.2 m）；
- 离线静态层不因实时空闲清除；
- 目标在 30 m 窗口外靠全局底图；
- 局部 SCAN 仍可能 200–500 ms；
- 实时建图不作为主验收；
- 真实建图闭环/定位 tracking 仍需现场验证。
